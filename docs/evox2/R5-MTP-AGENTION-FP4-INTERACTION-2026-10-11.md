## Future first-integrated-snapshot contract

1. Keep **Unsloth PLE16 + Unsloth Q8_0 MTP** as a frozen TG regression pair. Port/validate candidate TG patches **one at a time** on an isolated r5 research branch; never bake an unconditional dense-indexer optimization into the generic MTP path.
2. At the later integration boundary, bring **Agention FP4 main + matching FP4 MTP** in a **separate model-format/quant backend patch group**. Inspect **exact downloaded revisions and GGUF** via metadata scanner/dump: \`general.architecture\`, total/nextn layer counts, \`dsv4_compress_ratios\` including MTP layer, indexer tensors, \`blk.48.nextn.hc_head_*\` and quant types. Record binary/model SHA256. Model load and short generation first.
3. Native tests for **ratio0** and **ratio>0** MTP: indexer omission must take effect **only** on eligible ratio0; target no-op suppression must honor no-change only; include full/partial/zero acceptance, recurrent refusal/rollback, state restore (same-policy) and matched acceptance/output/logits where feasible. **A synthetic positive-ratio policy test does not replace a real compressed FP4 sidecar smoke.**
4. On Vulkan, first verify **matching f16 K/V** for target and FP4 draft if compatible, then compare author's q8_0 KV recommendation **as a distinct configuration**. Test fixed draft2 versus draft3/adaptive separately. **On ROCm/HIP**, confirm custom FP4 GGML operators/kernels actually exist and pass native backend tests before promising that backend.
5. Test the final integrated main+MTP combinations at **32k→64k→128k**, then 256k only with explicit memory/commit/fit safety gate; compare quality at controlled input/corpus and fixed decoding separately from TG performance. Preserve any unsupported model/ratio cases as **opt-out/fallback**, not a forced "fast path".
6. Use paired same-binary/fixture A/B for each optimization. Do **not** mix FP4 addition, dense/no-op patches, small-query union changes and new KV quantization in the same measurement. The first integrated release **is not built or verified** at this checkpoint.

**Decision:** No structural source-level conflict was found **provided both TG optimizations retain narrow applicability gates**. **Agention compressed/FP4 MTP remains unverified and is a required compatibility gate**; neither "will work" nor "incompatible" is supported until checking actual GGUF tensor/metadata and target backend.

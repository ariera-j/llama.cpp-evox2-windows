### PLE の確認

joined は head のグローバル行 `offset[h] + mixed % vocab[h]` を token-major で gather する。split は同じハッシュから `mixed % vocab[h]` を head-local 行として gather し、head の昇順で axis 0 に結合する。token ごとの埋め込みは共通の `[head_dim * n_heads, n_tokens]` となる。head の存在・最小行数を明示的に検査し、実寸を使って幅と余分な次元を通常の tensor ローダーで検証する。joined/virtual の lazy load、joined の prefetch と FP8 スケールはソースで維持を確認した。FP8・virtual 専用の実機テストは今回の IQ3 検証範囲外。

モデルはローカル設定の `UnslothOriginal`（UD-IQ3_XXS、3 シャード、各 10,946,624 / 49,567,921,344 / 32,382,955,968 bytes）および `UnslothPle16`（同モデルの split GGUF、81,961,816,672 bytes）。いずれも `C:/llama/models/unsloth_Qwen3.8-Flash-Next-GGUF/UD-IQ3_XXS/UD-IQ3_XXS` の既存ファイル。

Correctness coverage
--------------------
- Existing FLASH_ATTN_EXT test harness, CPU reference, unchanged NMSE
  tolerance 5e-4; this is not a bitwise-equivalence claim.
- Query counts 4, 63, 64, 65, 345, 512 and 1024.
- Overlapping and less-overlapping selections, duplicate and invalid
  indices, causal masking, fully masked rows and empty unions.
- KV sizes 1024, 4096, 32768, 65536, 131071, 131072, 131073, 262144.
- Top-k 17 and 2051; f16 and q8_0 fallback; strided K/V cache views.
- Cases above KV65536 use head size 64 to stay within this software
  driver's 128 MiB descriptor-range limit. Other new cases use head
  size 256. This does not validate a full 256k model execution.

Not verified here

- MTP or multi-conversation serving with QSA union enabled.
- MSVC versus LLVM performance.
- Generated-text quality beyond the output inspection performed during the
  recorded measurements.

Windows results
---------------
Target: Evo-X2, Ryzen AI Max+ 395 / Radeon 8060S, Windows 11,
96 GB GPU allocation, LLVM 20.1.8, Vulkan SDK 1.4.357.0.

- Test-Qsa-Union.ps1 -Suite Full: OFF and ON checks passed.
- Converted Unsloth, ctx65536: PP mean 227.26 off, 274.67 on.
- Agention ROCmFP4-FAST-v2-ple16, ctx65536: PP mean 227.12 off,
  273.22 on.
- Converted Unsloth, ctx131072, 126253 prompt tokens: PP 147.17 off;
  PP 222.38 and 223.16 on. The on mean is 222.77.
- TG was effectively unchanged by the QSA union path.
- min_kv 16384 was about 0.81 percent slower than 32768 at 64k.
- min_kv 26624 was about 0.19 percent faster than 32768 at 64k.
  This was treated as noise and the default remains 32768.

The later gather-stride experiment is not part of this stable source. Its
best 128k result differed from the stable r2 mean by about 0.33 percent,
below observed run-to-run variation.

Measurement script update
-------------------------
Measure-Qsa-Union.ps1 supports 64k, 128k and 256k contexts and checks the
logged min_kv value for every ON run. It clears the experimental
GGML_VK_QSA_GATHER_GROUPS variable during stable measurements. The rejected
gather experiment exposed a PowerShell scalar indexing error that passed the
first character of a value. The stable script has no gather parameter and
does not contain this path.
